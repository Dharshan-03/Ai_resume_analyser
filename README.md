# Ai_resume_analyser
![Resumind Banner](https://images.unsplash.com/photo-1586281380349-632531db7ed4?w=1200&h=400&fit=crop)

**Resumind** is a powerful, AI-driven SaaS platform designed to help job seekers optimize their resumes for Applicant Tracking Systems (ATS). By leveraging advanced AI analysis, it provides instant scoring, actionable feedback, and role-specific improvement tips to increase interview changes.



## ✨ Key Features

- **🛡️ AI Resume Analysis**: Upload your PDF and get an instant ATS compatibility score (0-100).
- **📊 Detailed Breakdown**: Visual insights on keyword matching, formatting, structure, and length.
- **💡 Smart Suggestions**: get tailored advice for specific roles (Software Engineer, Data Scientist, Product Manager, etc.).
- **📝 Templates Hub**: Access 12+ ATS-optimized resume templates for various career stages.
- **🔒 Privacy First**: Powered by **Puter.js** for secure, client-side faas processing without storing sensitive data.
- **🎨 Premium SaaS UI**: Built with a modern, glassmorphic design system featuring dark mode and smooth animations.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **Backend/AI**: Puter.js (Edge AI & Storage)
- **Deployment**: Vercel / Netlify

## 🚀 Getting Started

 **Install dependencies**
   ```bash
   cd Ai_Resume_Analyser
   npm install
   ```

 **Run the development server**
   ```bash
   npm run dev
   ```

 **Build for production**
   ```bash
   npm run build
   ```
